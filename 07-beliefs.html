Sheet 07 · §4 · Proposition 6

What can a private recommendation tell a team?

Read the corresponding paper sectionStudy side by side

Two agents assign rooms for a conference. A coordinator privately tells each agent which room it may use. A sensor later tells each one whether its assigned equipment arrived. The coordinator can correlate the room assignments before either sensor fires. The agents can also disagree about whether the equipment will arrive. What would it take to replace the coordinator's whole protocol with a single round of type reports?

This sheet builds the multi-agent model and proves the two inclusions in Proposition 6. Throughout, −i-i denotes everyone except ii, and Δ(E)\Delta(E) denotes probability laws on EE. Bergemann, Koh and Morris, Section 4

Exercise 1Two people can agree about the equipment

Let the state be a bit θ\theta. Under one common prior it is fair, a second bit ZZ is fair independently, and the second agent sees (Z,W)(Z,W), where W=θW=\theta if Z=1Z=1 and W=∗W=* otherwise. Agent 1 sees only ZZ. Both agents' payoffs and available actions are common knowledge and independent of ZZ.

Compute agent 1's probability of θ=1\theta=1 after each value of ZZ. If μ2\mu_2 denotes agent 2's probability of θ=1\theta=1, calculate the conditional distribution of μ2\mu_2 from agent 1's perspective. Suppose agent 1 receives a unit payoff if it correctly predicts whether agent 2 knows θ\theta. What information would be lost by replacing agent 1's type by its probability of θ=1\theta=1?

Hint

First compute the posterior of the person who sees WW. Then take its distribution given ZZ.

Worked solution

In both cases agent 1 assigns probability 1/21/2 to θ=1\theta=1. At Z=0Z=0, agent 2 also assigns 1/21/2, so agent 1 assigns probability one to μ2=1/2\mu_2=1/2. At Z=1Z=1, agent 2 observes the state, so agent 1 assigns probability 1/21/2 each to μ2=0\mu_2=0 and μ2=1\mu_2=1. The event that agent 2 knows the state is precisely Z=1Z=1. The full type earns one by predicting ZZ. A decision using only agent 1's state probability has success probability 1/21/2 under the common prior.

Exercise 2Build a belief hierarchy

Write Dj=(Aj,uj)D_j=(A_j,u_j) for the pair made up of agent jj's available actions and its payoff function on joint actions and the state. Begin with a singleton Hj0H_j^0. Define what agent ii believes at orders one and two and write the recursion at a general order. Explain how to test a proposed second-order law for consistency with a specified first-order law. Describe the additional object obtained when this construction is carried through every order.

Hint

The random object at order two includes each peer's first-order law. Projecting away a layer must recover the law already specified at the preceding order.

Worked solution

Write 𝒟j\mathcal D_j for the space of possible DjD_j. At order one the uncertainty concerns (θ,(Dj)j≠i)(\theta,(D_j)_{j\ne i}). At order two it also concerns each peer's first-order belief. In general,

Hik+1=Δ(Θ×∏j≠i(𝒟j×Hjk)).H_i^{k+1}=\Delta\!\left(\Theta\times \prod_{j\ne i}(\mathcal D_j\times H_j^k)\right).

Push a second-order law forward by forgetting the peers' beliefs. The result must equal ii's first-order law, including any correlations between the state and peer characteristics. At higher levels use the analogous truncations of peers' hierarchies. For example, a first-order state marginal of 1/21/2 is inconsistent with a second-order law assigning total mass 3/43/4 to θ=1\theta=1.

A type records DiD_i and a coherent hierarchy. The universal-space construction used in the paper represents such beliefs by a law βi[ti]\beta_i[t_i] of (θ,t−i)(\theta,t_{-i}). Its finite-order projections recover the beliefs just described. This representation theorem is an input from the theory of hierarchies. In a finite Bayesian model like Exercise 1, repeated conditioning and truncation already produce the example without constructing the entire universal space.

Exercise 3Whose probability enters the incentive constraint?

For a given type of agent 1, let the designer's conditional probability of θ=1\theta=1 be 1/41/4 and the agent's subjective probability be 3/43/4. Hold all other types fixed. Both agree on a private indicator ss with Pr(s=1∣θ=1)=4/5\Pr(s=1\mid\theta=1)=4/5 and Pr(s=1∣θ=0)=1/5\Pr(s=1\mid\theta=0)=1/5. Find their respective probabilities of θ=1\theta=1 given s=1s=1. What does the model's condition Γ(⋅∣ti)≪βi[ti]\Gamma(\cdot\mid t_i)\ll\beta_i[t_i] guarantee, and which of these posteriors determines a best response?

Hint

A likelihood is common to both calculations. Each calculation uses its own prior odds.

Worked solution

The likelihood ratio for s=1s=1 is four. The designer's posterior odds are 4/34/3 and its posterior is 4/74/7. The agent's posterior odds are 1212 and its posterior is 12/1312/13. Both assign positive mass to both states. More generally, if an event in (θ,t−i)(\theta,t_{-i}) has subjective probability zero for an agent, it also has conditional probability zero for the designer, for almost every own type under the designer's law. Equality of probabilities would impose a stronger restriction. The agent's 12/1312/13 is the relevant posterior at this decision. The designer averages achieved outcomes using Γ\Gamma and the common signal kernel π(ds∣θ,t)\pi(ds\mid\theta,t), which may correlate the agents' signals.

Exercise 4A lottery over plans is a joint lottery

Each room agent will have a private bit sis_i and may choose private room label 00, room label 11, or the action “wait.” The coordinator draws BB uniformly in {0,1}\{0,1\}. It gives agent 1 the plan “use room BB when your bit is one, otherwise wait” and gives agent 2 the same instruction with room 1−B1-B. Both agents can carry out all three actions. Assume the bits are independent of BB and that both bits being one has positive probability.

Conditional on both bits being one, compare the chance of a collision under this lottery with that under independent sampling from the two marginal plan lotteries. Specify the order of events in a direct mechanism.

Hint

The two room labels have identical uniform marginals in both experiments.

Worked solution

Under the shared draw the two active agents always get different rooms. Independent uniform draws collide with probability 1/21/2. Marginalizing and then independently sampling the recommendations changes the designer's outcome even if both agents obey.

Feasibility requires plans assigned to reported type hih_i to take values in Ai[hi]A_i[h_i].

Exercise 5Write down one complete deviation

Fix tit_i. Agent ii can send hi∈Ci(ti)h_i\in C_i(t_i), receive pip_i, see sis_i, and choose di(pi,si)∈Ai[ti]d_i(p_i,s_i)\in A_i[t_i]. Write its expected payoff Ji(hi,di∣ti)J_i(h_i,d_i\mid t_i) when all peers are truthful and obedient. State the full incentive inequality. Why can a false claim change both the peer actions and what the agent learns from its recommendation?

Hint

Keep track of which arguments are true types in π\pi and which are reports in γ\gamma. Write oi(pi,si)=pi(si)o_i(p_i,s_i)=p_i(s_i) for obedience.

Worked solution

Draw (θ,t−i)(\theta,t_{-i}) under βi[ti]\beta_i[t_i]. Given these objects, draw ss under π(⋅∣θ,t)\pi(\cdot\mid\theta,t) and draw pp independently under γ(hi,t−i)\gamma(h_i,t_{-i}). Set aid=di(pi,si)a^d_i=d_i(p_i,s_i) and ajd=pj(sj)a^d_j=p_j(s_j) for j≠ij\ne i. Then

Ji(hi,di∣ti)=𝔼[ui[ti](ad,θ)+ri((hi,t−i),ad,θ)].J_i(h_i,d_i\mid t_i)= \mathbb E\!\left[ u_i[t_i](a^d,\theta)+r_i((h_i,t_{-i}),a^d,\theta) \right].

For all such hi,dih_i,d_i, the requirement is Ji(ti,oi∣ti)≥Ji(hi,di∣ti)J_i(t_i,o_i\mid t_i)\ge J_i(h_i,d_i\mid t_i), together with feasibility of the recommendation rule. A claim can change the joint distribution of all plans. The realized private plan may itself reveal information about peer types through that distribution. Optimizing only over a fixed action chosen before the plan arrives can miss a profitable deviation.

Exercise 6Reconstruct the revelation principle

An indirect protocol has feasible input menus Xi(ti)X_i(t_i) and draws a private output vector yy from ρ(⋅∣x)\rho(\cdot\mid x) after inputs xx. Its reward is Ri(x,a,θ)R_i(x,a,\theta). In a pure equilibrium, let xi(ti)x_i(t_i) be the input and αi(ti,xi,yi,si)\alpha_i(t_i,x_i,y_i,s_i) be the action. Assume Xi(hi)⊆Xi(ti)X_i(h_i)\subseteq X_i(t_i) whenever hi∈Ci(ti)h_i\in C_i(t_i). Construct a direct protocol that reproduces the equilibrium outcome. Prove it satisfies Exercise 5. Prove the reverse inclusion of outcome sets.

Hint

Use the indirect protocol as a simulator. One sample of the entire output vector should supply all the plans. For the reverse direction use direct reports themselves as input symbols.

Worked solution

At reported profile hh form x(h)=(xj(hj))jx(h)=(x_j(h_j))_j and draw one vector yy from the original output kernel at x(h)x(h). Privately send each agent the function

pjhj,yj(sj)=αj(hj,xj(hj),yj,sj).p_j^{h_j,y_j}(s_j)=\alpha_j(h_j,x_j(h_j),y_j,s_j).

These functions have the required reported-type action ranges since the original strategies are feasible. Their joint law defines γ(h)\gamma(h). Pay ri(h,a,θ)=Ri(x(h),a,θ)r_i(h,a,\theta)=R_i(x(h),a,\theta). At truthful reports, the action profile conditional on (θ,t)(\theta,t) has exactly its original law: the same joint draw is used and the same signal kernel generates the private observations.

If agent ii could improve with (hi,di)(h_i,d_i) in this direct protocol, it could send xi(hi)x_i(h_i) in the indirect protocol. Menu inclusion makes that input available. From its private output yiy_i it can compute pihi,yip_i^{h_i,y_i} and, on receiving its true signal, take di(pihi,yi,si)d_i(p_i^{h_i,y_i},s_i). With the other agents fixed at equilibrium this gives exactly the same subjective payoff as the direct deviation. Original optimality precludes the improvement.

Conversely take any direct incentive-compatible protocol. Give the indirect protocol input menus Ci(ti)C_i(t_i), output alphabets equal to the plan spaces, joint output kernel γ\gamma, and rewards rir_i. Transitivity of the imitation relation gives menu inclusion. Honest inputs and obedient actions form an equilibrium by Exercise 5. Both directions concern outcome laws attainable in an equilibrium, allowing other equilibria in the same mechanism.
