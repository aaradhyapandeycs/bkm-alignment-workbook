Sheet 02 · §2.3 · Proposition 1

Turn a conversation into a contingent plan

A dispatcher emails a route card to a courier. Some cards say to take the north road if the bridge is open and the south road otherwise; other cards send the courier south in both cases. The courier receives the card before seeing the bridge status. If a reply were compressed to “go south,” which instruction had the dispatcher sent? A whole contingent plan is the right object to send before the courier's private observation.

Work with finite alphabets to see the proof by sums. In the paper the input and reply spaces may be Borel spaces, the rules and strategies are measurable, and a stochastic reply rule is a probability kernel. The same proof takes the image of that kernel under a measurable map to plans. Bergemann, Koh and Morris, §2.3 and Proposition 1

Exercise 1Forget everything about the envelope except its instructions

An indirect mechanism has input messages x∈X(t)x\in X(t) available to type tt, a reply yy with law ρ(⋅∣x)\rho(\cdot\mid x), and a reward R(x,a,θ)R(x,a,\theta) based on the input, action and state. The agent first sends xx, observes yy, privately learns ss, then picks an action in A[t]A[t]. For one type and one input, suppose the reply is uniform on four envelopes. The first two induce plan p(s)=sp(s)=s, the third p(s)=0p(s)=0, and the fourth p(s)=1p(s)=1, where s∈{0,1}s\in\{0,1\}. The binary signal agrees with the binary state with probability 4/54/5 in either state. Compute the law on plans and Pr(a=1∣θ)\Pr(a=1\mid\theta) under these instructions. Would sending the plans in unmarked envelopes change the answers?

Hint

A plan is a function on the entire signal alphabet. Two differently marked envelopes can contain the same function.

Worked solution

The identity plan has probability 1/21/2 and the two constant plans have probability 1/41/4 each. At state 11 the probability of taking action 11 is (1/2)(4/5)+1/4=13/20(1/2)(4/5)+1/4=13/20. At state 00 it is (1/2)(1/5)+1/4=7/20(1/2)(1/5)+1/4=7/20. Sending only the plan gives the same two conditional probabilities. Here the envelope draw is independent of the state given the input. If the courier has zero intrinsic utility and zero rewards, following these instructions is one equilibrium, so this calculation can also describe an equilibrium outcome. In the general reduction, different labels can carry incentives through the induced continuation behavior; the exercise below starts from a specified equilibrium to identify that behavior.

Exercise 2Build a profitable double deviation

A direct mechanism accepts a report j∈C(t)j\in C(t) and sends a random plan p:S→Ap:S\to A with law γ(j)\gamma(j). Assume one signal, one state, and two types. LL can only execute aa, while HH can execute aa or bb. Type HH may report either type; LL can only report LL. Both recommendations say to take aa, and intrinsic utilities vanish. The rewards on the HH report are r(H,a)=0r(H,a)=0, r(H,b)=−1r(H,b)=-1. On the LL report they are r(L,a)=−1r(L,a)=-1, r(L,b)=2r(L,b)=2. Check (i) disobedience following a truthful report and (ii) misreporting while still obeying. Then test the full incentive constraint.

Hint

Physical feasibility in the last stage uses the true type even when a different type was reported. A recommendation places no physical barrier in front of an alternative action.

Worked solution

For HH, obeying earns zero and truthful disobedience earns −1-1. Reporting LL and obeying earns −1-1. For LL there is no alternate action or report. Yet HH can report LL and choose bb, earning 22. This deviation is feasible even though an actual LL could never earn the reward attached to bb. A contract designer could remove this particular deviation by setting r(L,b)=−∞r(L,b)=-\infty; the published definition permits such prohibitions. What the example establishes is that the two restricted checks cannot establish incentive compatibility of the contract as written.

Exercise 3Write the entire deviation in one inequality

For a finite state and signal model, assume finite rewards in this exercise. Let tt be the true type, with prior h[t]h[t], signal experiment π[t]\pi[t], utility u[t]u[t], and action set A[t]A[t]. A report jj selects γ(j)\gamma(j) and r(j,a,θ)r(j,a,\theta). Define the truthful-and-obedient value VtV_t. Derive one inequality that tests an arbitrary feasible report and plan-dependent action rule dd. Then condition on the recommendation and positive-probability signals to simplify the optimal deviation payoff. What does this say about obedience on the truthful report?

The agent can reoptimize for each pair (p,s)(p,s) after choosing one report jj before learning either. A reward in this question may depend on the state.

Exercise 4Construct the direct mechanism from an equilibrium

Fix a measurable pure equilibrium of an arbitrary indirect mechanism. Write x(t)x(t) for the equilibrium input and α(t,x,y,s)\alpha(t,x,y,s) for its continuation action. Assume t⊵jt\trianglerighteq j implies X(j)⊆X(t)X(j)\subseteq X(t). Construct a direct rule γ(j)\gamma(j) and rewards r(j,a,θ)r(j,a,\theta) from these data. Prove action feasibility, equality of the joint law of (θ,t,a)(\theta,t,a), and incentive compatibility. Keep track of which type each expression uses when tt imitates jj.

Hint

Use the indirect reply as a private random seed for generating a plan. For incentive compatibility, an agent deviating in the indirect mechanism is allowed to compute what that plan would have been.

Worked solution

After receiving jj, the designer draws yy from ρ(⋅∣x(j))\rho(\cdot\mid x(j)) and forms the plan

pj,y(s)=α(j,x(j),y,s).p_{j,y}(s)=\alpha(j,x(j),y,s).

Use its image law as γ(j)\gamma(j), and set r(j,a,θ)=R(x(j),a,θ)r(j,a,\theta)=R(x(j),a,\theta). The recommended action belongs to A[j]A[j] for each signal, by feasibility of the original strategy. Under truth and obedience one may couple the direct and indirect mechanisms using the very same (θ,t)(\theta,t), true signal ss, and reply yy. In both the played action is α(t,x(t),y,s)\alpha(t,x(t),y,s). This proves equality of the whole joint outcome law under the designer's Γ\Gamma, including any dependence between types and states.

For any direct deviation (j,d)(j,d) of true type tt, the corresponding indirect deviation sends x(j)x(j). This input is available since x(j)∈X(j)⊆X(t)x(j)\in X(j)\subseteq X(t). Upon seeing the reply it constructs pj,yp_{j,y} and plays d(pj,y,s)∈A[t]d(p_{j,y},s)\in A[t]. The true signal still follows π[t]\pi[t] and the payoff uses u[t]u[t]. The constructed strategy has exactly the direct deviation's value under h[t]π[t]h[t]\pi[t]. The original equilibrium already bounds this value by the truthful path payoff. Since this works for every (j,d)(j,d), truth and obedience are optimal in the constructed mechanism.

Exercise 5Recover the converse and identify what is implemented

Let 𝒪\mathcal O consist of all joint laws of state, type and action arising in some equilibrium of some indirect mechanism. Let 𝒪IC\mathcal O^{\rm IC} collect the laws from truthful and obedient play of action-feasible, incentive-compatible direct mechanisms. Turn any such direct mechanism into an indirect one. Where do reflexivity and transitivity enter? Deduce Proposition 1 and write the designer's optimization problem. Finally, give a direct example where another equilibrium delivers a different human payoff.

Hint

Use the same objects with different names. Check the indirect rule's input-menu monotonicity before invoking the definition of equilibrium.

Worked solution

Choose X=𝕋X=\mathbb T, X(t)=C(t)X(t)=C(t), Y=ASY=A^S, ρ(⋅∣j)=γ(j)\rho(\cdot\mid j)=\gamma(j) and R(j,a,θ)=r(j,a,θ)R(j,a,\theta)=r(j,a,\theta). Reflexivity makes tt available to type tt. If t⊵jt\trianglerighteq j and k∈C(j)k\in C(j), then t⊵kt\trianglerighteq k by transitivity, so C(j)⊆C(t)C(j)\subseteq C(t). The indirect input menus are therefore admissible. The original incentive inequality bounds every alternative input and continuation rule. Consequently truth and obedience give an indirect equilibrium with the required law, proving 𝒪IC⊆𝒪\mathcal O^{\rm IC}\subseteq\mathcal O. The construction in Exercise 4 proves the reverse inclusion.

Thus the designer can optimize sup(γ,r)𝔼[v(a,θ)]\sup_{(\gamma,r)}\mathbb E[v(a,\theta)] over action-feasible, incentive-compatible direct mechanisms, with expectations under the truthful law. The rewards enter the agent's payoff; the paper specifies the human's payoff as v(a,θ)v(a,\theta). For an example of multiplicity take a single state, signal and type, actions 0,10,1, and human payoff v(a)=av(a)=a. Give the agent zero utility and zero rewards for both actions. Recommend 11. Obedience is optimal and delivers human payoff one, while always taking 00 is also an equilibrium and delivers zero. Equality of the sets of attainable laws is a partial implementation statement. Guaranteeing a target in every equilibrium would require a different argument.
