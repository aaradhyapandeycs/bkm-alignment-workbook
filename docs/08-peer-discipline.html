Sheet 08 · §5 · Example III · Proposition 7

Paying an agent for predicting its peer

Read the corresponding paper sectionStudy side by side

Two reviewers choose whether to release a catalog. Each would enjoy pressing the release button. The editor wants release only when both private checks were favorable. The editor can record both reports and both buttons, but learning the true quality of the catalog could take weeks. Can one reviewer’s report help discipline the other? The distinction between forecasting an honest peer and simply agreeing with a peer drives this sheet.

We begin with the binary instance of Example III, use it to build Proposition 7 for a finite supported type model, and then test its assumptions. Bergemann, Koh and Morris, Section 5, Example III

Exercise 1A low report predicts a high peer

Let θ∈{0,1}\theta\in\{0,1\} be fair. If θ=1\theta=1 the types are (H,H)(H,H). If θ=0\theta=0 the ordered pair is equally likely to be (H,L)(H,L) or (L,H)(L,H). Each agent sees its own type and learns nothing further before acting. The common prior is as given. Compute each type's conditional law of the other type, with coordinates ordered (H,L)(H,L). Compute also its conditional probability of θ=1\theta=1. Each reviewer chooses a bit and likes its own bit to equal one. Which rule earns the editor a unit payoff for both actions being correct?

Hint

The unconditional probability that your own type is HH is 3/43/4. Seeing LL leaves only one possible peer type.

Worked solution

For either agent, the peer forecast given HH is pH=(2/3,1/3)p_H=(2/3,1/3) and that given LL is pL=(1,0)p_L=(1,0). The state probabilities of one are respectively 2/32/3 and zero. Although a single HH leaves doubt, the joint type determines the state. With truthful reports, recommend action b=1b=1 to both agents at (H,H)(H,H) and b=0b=0 otherwise. This yields human payoff one with certainty if both agents obey. A bonus for matching the peer's report would give an LL type a reason to say HH.

Exercise 2Derive the scoring rule and fill the ledger

For a reported forecast vector qq on a finite set YY and a realized peer report yy, define S(q,y)=2q(y)−∑z∈Yq(z)2S(q,y)=2q(y)-\sum_{z\in Y}q(z)^2. If the genuine forecast is pp, find the expected loss from submitting qq instead. In Exercise 1 compute the score for each of the four ordered pairs (own report, peer report), and each type's expected scores for truth and a lie.

Hint

Complete the square in 2⟨p,q⟩−∥q∥222\langle p,q\rangle-\|q\|_2^2. For a peer forecast (2/3,1/3)(2/3,1/3) the sum of squares is 5/95/9.

Worked solution

The expected score equals ∥p∥22−∥p−q∥22\|p\|_2^2-\|p-q\|_2^2. Truth maximizes it strictly whenever a different report represents a different forecast. An HH report scores 7/97/9 against HH and 1/91/9 against LL. An LL report scores 11 against HH and −1-1 against LL.

With an honest peer, an HH type's expected scores are 5/95/9 for truth and 1/31/3 for a lie. An LL type's corresponding scores are 11 and 7/97/9. Both lose 2/92/9, the squared Euclidean distance of the two forecast vectors. An individual draw can reward a lie more highly. The incentive calculation uses the expected score at the time of reporting.

Exercise 3Forecasts alone do not move the buttons

Suppose agent ii's private utility is aia_i and its feasible actions are 0,10,1. Let the target b(h)b(h) at reports hh be as in Exercise 1. First suppose an agent is paid only a positive multiple Λ\Lambda of its score, independently of the buttons. What will it do when b(h)=0b(h)=0? Now construct a reward schedule that enforces the recommendation and induces honesty. Does the schedule for this particular example require the editor to observe the state?

Hint

Make the total payoff on the recommended action profile equal to the peer score. Use the paper's allowance of an extended-real penalty elsewhere.

Worked solution

If the reward is independent of the action, switching one's own bit from zero to one gains one unit. Instead, when both buttons equal b(h)b(h) pay each ii the amount ΛS(phi,hj)−ai\Lambda S(p_{h_i},h_j)-a_i, and pay −∞-\infty otherwise. If the peer follows its recommendation, choosing the prescribed bit gives the finite score and choosing the opposite bit incurs the penalty. This holds after either feasible report. Reporting honestly then gains 2Λ/92\Lambda/9 over the alternative, so any Λ>0\Lambda>0 works. The editor's state-contingent objective is attained using the observed reports and buttons. No payment here depends on θ\theta.

Exercise 4Which beliefs can a peer report distinguish?

For each ii, let Ti0T_i^0 be the finite marginal support of its type under the designer's distribution Γ\Gamma. Write pi(ti)p_i(t_i) for its subjective probability vector on Yi=∏j≠iTj0Y_i=\prod_{j\ne i}T_j^0. Assume the type assigns all its peer-type probability to this product. Suppose two own types give distinct predictions about θ\theta but the same vector pip_i. Can a function of these two candidate reports and a single truthful peer profile make honesty strictly optimal for both through the scoring term alone? Now assume pip_i is injective on Ti0T_i^0 for every ii. Why is there a single positive separation for all distinct supported pairs?

Hint

For the first question, compare the expected score difference for the two possible genuine types. For the second, consider squared Euclidean distances on each finite peer alphabet.

Worked solution

For two reports t,ht,h with the same peer prediction pp, the expected score advantage of reporting tt instead of hh is the same number for both genuine types, namely ∑yp(y)[S(t,y)−S(h,y)]\sum_y p(y)[S(t,y)-S(h,y)] for any proposed peer-only score SS. It cannot be strictly positive for one type and strictly negative for the other. This applies even when the joint beliefs on (θ,t−i)(\theta,t_{-i}) are different. The marginal on the observable peer reports drives the test.

If there is at least one distinct pair, the finite minimum

δ=mini, t,h∈Ti0, t≠h∥pi(t)−pi(h)∥22\delta=\min_{i,\ t,h\in T_i^0,\ t\ne h}\|p_i(t)-p_i(h)\|_2^2

is positive by injectivity. If every marginal support is a singleton, there is no supported misreport to deter. An infinite collection of different forecasts can have arbitrarily small distances. For example, the Bernoulli probabilities 1/2+1/(4k)1/2+1/(4k) are all different for integer k≥1k\ge1, while neighboring vectors approach each other.

Exercise 5Derive the reward for an arbitrary feasible target

Use at least two agents. The primitive action and state sets are finite, the supported own types are finite, and private utilities ui[ti](a,θ)u_i[t_i](a,\theta) are real-valued. Assume belief closure and peer separation as in Exercise 4. Any own type can claim any report. Let γ(h)\gamma(h) draw private plans conditional on report profile hh, each feasible for its reported type. Define Kθ(h)K_\theta(h) as the support of the resulting played action profile when the plan draw is evaluated at signals from π(⋅∣θ,h)\pi(\cdot\mid\theta,h). Even at a report profile with zero designer probability, these kernels are specified.

Find a transfer using only the reported types, the actual action profile, and the state that implements γ\gamma on the supported types. Give a bound on the scale sufficient against a joint report-and-action deviation. Distinguish the uses of belief closure, separation, and action feasibility in your proof.

Hint

On Kθ(h)K_\theta(h) cancel the reported private utility. Ask what part of the true utility survives when the reported type differs from the true type. A uniform bound can ignore whether every conceivable action is attainable by the deviation.

Worked solution

On a profile of individually supported reports and for a∈Kθ(h)a\in K_\theta(h), set

ri(h,a,θ)=ΛS(pi(hi),h−i)−ui[hi](a,θ).r_i(h,a,\theta)=\Lambda S(p_i(h_i),h_{-i})-u_i[h_i](a,\theta).

Give −∞-\infty otherwise. At truth all peer reports are in the supported alphabet almost surely by belief closure. The prescribed plan is feasible, and under the true signal kernel obedience lands in Kθ(t)K_\theta(t) almost surely. Private utility cancels there. Any action under a truthful report that stays on target earns the same score. An action putting positive probability on the forbidden set gives expected payoff −∞-\infty. Thus obedience is optimal.

Let MM be the largest absolute discrepancy ∣ui[ti](a,θ)−ui[hi](a,θ)∣|u_i[t_i](a,\theta)-u_i[h_i](a,\theta)| across all players, supported own-type pairs, action profiles and states. Finiteness guarantees M<∞M<\infty. A report outside Ti0T_i^0 is always penalized. For a supported lie followed by any action rule that gives finite expected payoff, the score loses at least Λδ\Lambda\delta in expectation because peers report their true types. The discrepancy in intrinsic utility and its cancellation can recover at most MM, even if the deviator uses everything learned from its private plan and true signal. The gain over truth is at most M−ΛδM-\Lambda\delta. Choosing Λ≥M/δ\Lambda\ge M/\delta gives weak incentives and choosing a strict inequality makes every supported false report strictly worse. If there are no distinct pairs, omit this bound. This proves Proposition 7 under its support-wise criterion.

The proof uses the agents' own peer forecasts. They need not coincide with the designer's conditional beliefs. The general cancellation and support test can require verifiable state-dependent payments even though Exercise 3 avoided them. An unbounded scoring scale and exclusion penalties are part of this benchmark.

Exercise 6What does the implementation guarantee?

Keep Exercise 1's type law and utilities, but let a new rule γ\gamma draw the two recommended action bits independently and fairly at every report profile, with the same rule in both states. Both actions are feasible for both types, and there are no further signals. Apply Exercise 5's mechanism. Do truthful reports followed by obedience form an equilibrium? Can the same mechanism have a different equilibrium outcome even when supported reports strictly prefer honesty against truthful peers?

Hint

Determine Kθ(h)K_\theta(h). Once private utility is canceled, examine the payoff from any played action profile.

Worked solution

The target support is {0,1}2\{0,1\}^2 for every h,θh,\theta. Thus every action profile leads to exact cancellation and the only remaining payoff is the report score. Against a truthful peer both types strictly prefer honesty for any Λ>0\Lambda>0. Playing the recommended bits is a best response, so the independent fair actions are attained in equilibrium.

There is also an equilibrium in which both agents tell the truth and always play zero. The reports remain optimal and every action is a best response at every recommendation. Its action distribution is a point mass. The theorem constructs one truthful and obedient equilibrium for the target, and the proof enforces membership of the permitted support. A claim about the distribution in every equilibrium would require another argument.
